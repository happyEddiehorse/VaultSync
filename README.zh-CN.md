# VaultSync

[English](README.md) | 简体中文

VaultSync 是一个 Android 应用，用于同步手机上的文件夹与远端 Git（HTTPS 或 SSH）仓库。
点一下**同步**，它会提交你的改动、合并远端的改动，再推送上去。自带简单的冲突解决界面。

它最初是为了同步 [Obsidian](https://obsidian.md) 笔记而写的，用在这上面很合适，但它不依赖 Obsidian——
任何有 Git 远端的文件夹都可以同步。

## 功能

**添加仓库**
- 把远端仓库克隆到手机上的文件夹。
- 把手机上已有的文件夹初始化成新仓库，推送到空的远端仓库。
- 或直接接管已经有 `.git` 的文件夹。
- 开始之前可以先测试连接。

**同步**
- 点一下：提交全部改动 → 获取远端 → 合并 → 推送。推送时远端又有了新提交，会自动再获取、合并一次。
- 不会 rebase，也不会强制推送；远端的历史只会增加，不会被改写。
- 多个仓库，各自显示状态。同步排队依次执行，在前台服务里运行，有进度通知，可以取消。
- 出错时写清楚：哪一步失败、可能的原因、怎么处理；原始信息和日志点一下就能看。

**冲突**
- 有冲突的文件按原文连续显示，冲突就地展开，可选保留本地、保留远端、两者都保留（可选先后），或手动编辑。
- 左侧同时显示本地与远端双方行号、不同之处高亮；整篇编辑器支持查找，留下冲突标记时会提醒。
- 二进制文件、单方删除了的文件，可直接以文件为单位处理。
- 可以一次全部用本地或全部用远端，也可以放弃本次合并。

**历史**
- 当前分支的提交历史，并标出还没推送的提交。
- 每个提交改了哪些文件，逐个展开看改动：行号、字词级高亮、自动折叠没有变动的行、可开关自动换行。

**认证与网络**
- HTTPS：用户名 + 令牌。
- SSH：在应用里生成（Ed25519）或导入密钥（OpenSSH、PEM 格式，支持口令），每个仓库可选用不同的密钥。
- 首次连接时记下主机密钥，之后密钥有改动就会拒绝连接。已内置 GitHub 的主机密钥；GitHub 的 SSH 可一键切换 443 与 22 端口。
- 令牌和私钥用 Android Keystore 里的密钥加密保存。
- 可设置 HTTP 代理，设置后 HTTPS 和 SSH 连接走代理。

**维护**
- 检查同步被打断后留下的问题（锁文件、没完成的合并），提供修复。
- 显示仓库占用的空间，必要时会建议整理（Git 垃圾回收）。
- 文件夹不在了（比如换了手机），可以把仓库重新克隆到原位置。
- 把应用的配置导出成文件（可选是否包含令牌和私钥，包含时用口令加密），恢复时可手动选择恢复项。

**其它**
- 每个仓库可以单独设提交者姓名、邮箱，提交信息模板可带日期（默认 `vault backup: {{date}}`）。
- 每次同步、克隆、整理都有日志，可复制、分享；可打包诊断文件用于反馈问题。
- 8 种界面语言：English、简体中文、繁體中文、日本語、Deutsch、Español、Français、Русский，未来可能支持更多。
  除英文和简体中文外，其它语言都是机器翻译，未经人工审校；欢迎熟悉这些语言的朋友通过 Issue 或 Pull Request 帮忙改进。
- 浅色、深色主题，Android 12 及以上支持动态取色。

## 限制

- 没有自动同步：不做定时同步，也不通过在后台监听其它应用的状态来自动同步，只在用户主动点的时候同步。
- 只在当前检出的分支上工作；暂不支持切换分支、rebase、cherry-pick、子模块、Git LFS，未来可能考虑支持。
- 文件夹必须是共享存储里的普通文件夹（例如 `Documents/`），不支持其它应用通过存储访问框架（SAF，如网盘挂载、部分应用私有文档目录）提供的虚拟文件夹。
- 只在 Android 10 及以上测试过，暂不考虑支持更低的版本。

## 开始使用

1. 从 [Releases](https://github.com/happyEddiehorse/VaultSync/releases) 下载 APK 并安装。需要 Android 10 及以上。
2. 打开 VaultSync，按提示授予文件访问权限（Android 11 及以上是"所有文件访问权限"）。
3. 点右下角 **+**，选择开始方式（克隆、新建仓库、已有仓库），再选文件夹。
4. 填远端地址：
   - HTTPS，例如 `https://github.com/用户名/仓库.git`，再填用户名和个人访问令牌。
     GitHub 上用细粒度令牌（fine-grained token），给这个仓库 *Contents: Read and write* 权限就够了。
   - SSH，例如 `git@github.com:用户名/仓库.git`：在应用里生成密钥，复制公钥，添加到 Git 服务上
     （GitHub 上可以添加为仓库的 Deploy key 并勾选“Allow write access”写权限，或添加到账号的 SSH keys）。
5. 确认提交者姓名和邮箱，等第一次克隆或推送完成。
6. 以后想让手机和远端保持一致时，点**同步**即可。

## 配合 Obsidian 使用

- 库放在共享存储里，例如 `Documents/<库名>`；具体位置可以在 Obsidian 的"管理库"里看到。
- 推荐和桌面端的 [obsidian-git](https://github.com/Vinzent03/obsidian-git) 插件同时用在同一个仓库上；默认的提交信息与插件一致。
- 应用可以添加推荐的忽略规则，忽略每台设备都不一样的文件（如 `.obsidian/workspace.json`），免得它们引起冲突。
- 建议在手机上开始编辑前、编辑完后各同步一次，电脑上也如此，以减少冲突。

## 构建

需要 JDK 21 和 Android SDK。

```bash
./gradlew :gitcore:test        # 同步引擎的单元测试（纯 JVM）
./gradlew :app:assembleDebug   # debug 包在 app/build/outputs/apk/debug/
```

`gitcore` 模块包含 Git 和同步逻辑，不依赖 Android；`app` 模块则包含 Compose 界面和平台相关代码。
JGit 锁定在 5.13.x：更新的版本调用了 Android 10 所没有的 JDK API。
